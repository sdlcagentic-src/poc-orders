# poc-orders

Target workspace for a proof of concept of an agentic software delivery platform.

An automated bot (a GitHub App) proposes each change as a pull request on its own branch. A human reviews and merges it. Nothing is written to `main` directly.

## Layout

The folders appear as the platform runs its stages:

- `docs/` requirements, stories, domain language, architecture decisions
- `contracts/` OpenAPI and AsyncAPI contracts
- `foundation/` shared starters
- `services/` generated services and the UI

## Content

Everything here is generated sample material for an order-management demo. It contains no confidential data and no real customer data.
