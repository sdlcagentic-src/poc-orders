# Shared foundation: React

Generated by the platform from the stack profile `react-ui`. Do not edit by hand: change the configuration and generate again.

## What it gives a user interface

- `createApiClient`: a typed client (openapi-fetch) with a request timeout (`request-timeout-ms`: 5000) that turns every error response into an `ApiError` (RFC 7807 problem documents are read).
- Bearer tokens (`auth`: bearer): the client sends `Authorization: Bearer <token>` from a `getToken` function; `AuthProvider` and `useAuth` carry it through the component tree.
- `ErrorBoundary` and `ProblemAlert`: a rendering error or a failed call is shown, never a blank page.
- `AppShell`: a header, navigation and an outlet for react-router routes.
- `logger`: console logging with personal data redacted (`log-masking`: email).

## Using it in a user interface service

In `services/<name>/package.json`: `"@foundation/ui": "file:../../foundation/react-ui"`. The library exports its TypeScript source, so there is nothing to build first.

Generate the types of a contract in the service: `openapi-typescript ../../docs/contracts/<contract>.yaml -o src/generated/<contract>.d.ts`, then `createApiClient<paths>({ baseUrl })`.

Add `node_modules/` to the repository's `.gitignore` (the platform's bot cannot write hidden files). Node 20.19 or later.

## Dependencies

`package-lock.json` pins every package with its integrity hash; install with `npm ci --ignore-scripts`. To update a dependency, change `package.json` in the profile (`workflow/src/main/resources/stacks/react-ui/foundation/`), run `npm install --package-lock-only --ignore-scripts` there and commit both files; a test fails if they disagree.
